# Gestión de Reservas en un Cine

Este proyecto simula un sistema de reservas para un cine local que busca modernizar su proceso de asignación de asientos. Utiliza JavaScript y programación orientada a objetos para representar salas, asientos y operaciones de reserva.

## Objetivo

Desarrollar una aplicación en JavaScript que permita:

- Representar salas de cine y sus asientos.
- Reservar y cancelar asientos.
- Mostrar los asientos disponibles en tiempo real.
- Simular el flujo de reservas con datos de prueba.

 **Simulación de flujo**  
   - Se incluyen datos de prueba para simular reservas, cancelaciones y visualización del estado actual de los asientos.
