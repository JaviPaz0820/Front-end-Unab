# M5AE3 - ABP3 | Actividad de Lógica y Razonamiento en JavaScript

##  Objetivo

Reconocer los elementos fundamentales del **DOM (Document Object Model)** y aplicar **funciones callback** en JavaScript para manipular dinámicamente un documento HTML.

---

##  Estructura del Proyecto
Front-end-Unab/ 
│ ├── index.html 
├── CSS/ 
│ └── style.css 
└── JS/ 
└── main.js


---

##  Ejecución

1. Clona el repositorio o descarga los archivos.
2. Abre `index.html` en tu navegador.
3. Presiona `F12` para abrir la consola y observar la salida.
4. También verás los resultados en pantalla gracias a la manipulación del DOM.

---

##  Conceptos Aplicados

- **Funciones callback**: Se utilizan como parámetros para ejecutar lógica personalizada.
- **Manipulación del DOM**: Se accede y modifica el contenido de la página usando `document.getElementById()` y `createElement()`.
- **Interpolación dinámica**: Los mensajes se adaptan automáticamente según los valores ingresados.
- **Modularidad y claridad**: El código está organizado en funciones reutilizables y bien comentadas.

---

##  Validación

Al ejecutar el proyecto, se deben mostrar los siguientes mensajes tanto en consola como en pantalla:
¡Buenos días! 
¿Quieres un café?
La diferencia entre 5 y 3 es: 2
Elevando 5 a potencia 3 se obtiene: 125


Puedes cambiar los valores `5` y `3` en `main.js` para verificar que los mensajes se actualizan dinámicamente.
