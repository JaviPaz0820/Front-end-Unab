# Vue 3 + Vite: Tabla de usuarios 

Proyecto en Vue 3 creado con Vite. Muestra una tabla de usuarios (Nombre, Apellido, Fecha de Nacimiento y Edad) estilizada con Bootstrap 5.

# Requisitos 
- Node.js

# Instalación

npm install

# Desarrollo
 Inicia el servidor de desarollo en modo HMR:
 npm run dev

 La app quedará disponible en la URL que indique la terminal (por defecto http://localhost:5173)

 # Build de producción

npm run build
npm run preview
