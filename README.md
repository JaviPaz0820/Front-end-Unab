# 📦 Front-end UNAB — M2AE5 ABPRO5

Proyecto desarrollado como parte del módulo ABPRO5 del curso de Front-end en la Universidad Andrés Bello. Este repositorio contiene una aplicación web construida con tecnologías HTML, CSS y JavaScript, enfocada en la implementación de componentes visuales y funcionales para una experiencia interactiva.

---

## 🚀 Características principales

- Estructura modular con carpetas separadas para estilos (`css/`) y scripts (`js/`)
- Página principal `index.html` con integración de estilos y lógica
- Uso de JavaScript para manipulación dinámica del DOM
- Diseño responsivo adaptado a distintos dispositivos

---

## 📁 Estructura del proyecto

Front-end-Unab/ ├── css/ │ └── estilos.css ├── js/ │ └── script.js └── index.html


---

## 🛠️ Tecnologías utilizadas

- **HTML5** — estructura semántica de la página
- **CSS3** — estilos personalizados y diseño responsivo
- **JavaScript** — lógica de interacción y manipulación del DOM
