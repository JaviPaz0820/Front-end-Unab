# 🌐 Portafolio Profesional — Javiera Ampuero Millaquipai
-Bienvenida/o a mi portafolio profesional, una plataforma desarrollada con Vue 3 + Vite donde presento mis proyectos, habilidades técnicas, experiencia y formas de contacto.
Este sitio fue diseñado con un enfoque moderno, accesible y altamente visual, integrando buenas prácticas de desarrollo frontend, UI/UX y optimización web.

--- 

## 🎯 Objetivo del Proyecto
Construir un portafolio rápido, responsivo y funcional que refleje mis habilidades como Desarrolladora Front-End Junior, integrando:
- Componentización con Vue 3
- Renderizado eficiente con Vite
- Animaciones suaves mediante Intersection Observer
- Carruseles personalizados en proyectos y habilidades
- Diseño limpio, profesional y adaptado a todos los dispositivos
- Presentación clara de mis proyectos y fortalezas

--- 

## 🚀 Tecnologías Utilizadas
- Vue 3 (Composition API)
- Vite
- HTML5
- CSS3 (Flexbox, Grid, Custom properties)
- JavaScript ES6+

## ⚙️ Instalación y uso local
1. Clonar el proyecto
   git clone https://github.com/JaviPaz0820/Front-end-Unab.git
cd Portafolio-Final

2.Instalar dependencias
npm install

3. Levantar entorno de desarrollo
   npm run dev

4. Compilar
   npm run build
