# Actividad M6AE2 - Proyecto Pokémon en Vue

Este proyecto forma parte de la actividad **M6AE2-ABP2** del módulo de Front-End en la Universidad Andrés Bello. El objetivo es construir una aplicación web utilizando **Vue 3 + Vite** que muestre una lista de personajes Pokémon con sus respectivas imágenes y descripciones.

## Tecnologías utilizadas

- [Vue 3](https://vuejs.org/)
- [Vite](https://vitejs.dev/)
- HTML5 + CSS3
- JavaScript (Composition API)

## Estructura del proyecto
pokemon-list/ 
├── src/ 
│ ├── App.vue 
│ ├── assets/ 
│ └── main.js 
├── public/ 
├── package.json 
└── README.md


## Funcionalidades

- Renderiza una lista de 5 Pokémon con nombre, imagen y descripción.
- Usa `v-for` para recorrer los personajes.
- Muestra un mensaje si no hay Pokémon disponibles.
- Estilos responsivos y visualmente agradables.

## Instalación y ejecución

1. Clona el repositorio (si no lo tienes local):
   ```bash
   git clone https://github.com/JaviPaz0820/Front-end-Unab.git
   cd Front-end-Unab
   git checkout m6ae2-abp2

2. Instala las dependencias
   npm install

3. Ejecuta el servidor de desarrollo
npm run dev

4. Abre tu navegador en http://localhost:5173
